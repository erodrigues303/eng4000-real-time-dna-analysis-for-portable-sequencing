# Model catalogue

JSON records are the editable metadata source; paired Markdown cards are generated by `python harness/analysis/render_summaries.py`. Unknown fields render as `TBD — needs verification`. IDs distinguish exact identified models from partially identified/review-only candidates. Chemistry never substitutes for architecture.

Dorado HAC v6, its modified-base companion, Blitz network 64 and the partially identified Slorado HAC v5 have reported executions. DeepNano-Coral is review only. SoCall is restricted/planned and no implementation details are published.

Bonito v1.1.0 was reviewed (B p.7; P p.7): PyTorch LSTM/CRF and transformer configurations, with a historical Linux x86_64/CUDA dependency limitation. No particular tested model/weights is identified, so no fabricated Bonito model card is created. Exact Fast/HAC models for D2/D3 are also unidentified. Pin them before adding cards. Parameter counts for every listed model remain TBD.
