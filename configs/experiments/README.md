BLITZ-009's exact build/network settings must be recovered, not inferred from desktop tests.

Reproduction sequence: recover exact commands/environment and raw artifacts; verify dataset/model hashes and system card; resolve null settings; run a smoke test; apply the selected scenario's warm-up/repetition policy; archive originals and output checks; generate summaries.
