# Reading the results

All current numerical records are **preliminary report transcriptions**, not newly executed or independently validated results. Read the [generated tables](../../results/summaries/historical-summary.md), their individual source pages and scope notes, and the [source conflicts](../sources.md).

Dorado D1 has 59 reads; Blitz D4 has 48. D5 has 4,467 reads and supports repeated approximately five-minute processing, not live acquisition. Byte equality and matching sequence/quality strings are regression checks, not reference accuracy. BLITZ-001/002 report byte-identical repeat output, but against expected.fastq only 34 sequences were exact prefixes; 14 needed 1–6 edits with trailing output unpenalized (B p.11). These are not empirical accuracy scores.

Do not compare a short Dorado stage rate against full-command Blitz rates as a controlled head-to-head result. Do not rank package, module and unknown-scope power as equivalent. No validated SoCall, live-streaming or reference-accuracy result is available. SOCALL-001/002 are preliminary single laptop runs: read identity on D5 against Wick's reference, not embedded performance.
